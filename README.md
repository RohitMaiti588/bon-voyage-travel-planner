# Bon Voyage — Travel Itinerary Planner

A beginner-friendly HTML, CSS, and JavaScript travel planner. It lets you create and edit trips, choose a cover image, record transport and accommodation details, separate check-in/check-out dates and times, tick passport/visa reminders, write a backup plan, save favourites, search trips, switch themes, and print an itinerary.

## Run the project
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Create a trip using **Create a trip**.

## Files
- `index.html` — page structure and forms.
- `style.css` — layout, colours, responsive design, and dark mode.
- `script.js` — trip form actions, browser storage, filters, and printing.
- `logo.svg` — project logo.

## Notes
- Trip and demo account information is stored in the current browser using local storage; there is no server or real account security.
- Cover images are stored in the browser with the trip. Use images smaller than 1 MB to avoid browser storage limits.
- Do not enter real passwords or sensitive personal information.
